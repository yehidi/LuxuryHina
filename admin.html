התחברות

כדי לערוך את התוכן והעיצוב של האתר, יש להתחבר עם טוקן גישה אישי מ-GitHub.

איך יוצרים טוקן? ולמה זה בטוח?

ליצירת טוקן חדש (פעם ראשונה בלבד):

  1. היכנסו לכתובת: github.com/settings/personal-access-tokens/new
  2. תחת Repository access בחרו Only select repositories ובחרו את LuxuryHina בלבד.
  3. תחת Permissions → Repository permissions אתרו Contents ושנו ל-Read and write.
  4. לחצו Generate token והעתיקו את הטוקן שמתחיל ב-github_pat_.
  5. הדביקו אותו כאן ולחצו התחבר.

למה זה בטוח: הטוקן נשמר רק בדפדפן שלכם (על המחשב הזה בלבד) ואף פעם לא נשלח לשום שרת חוץ מ-GitHub עצמו. אם תגדירו אותו כמומלץ למעלה, הוא יכול לגעת רק באתר הזה — לא בשום דבר אחר בחשבון שלכם. אפשר תמיד לבטל אותו דרך אותו עמוד ב-GitHub (כפתור Delete).
