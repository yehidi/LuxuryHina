## איך להוסיף או להחליף תמונה

1. גלשו ל-`github.com/yehidi/LuxuryHina` → תיקיית `images`
2. `Add file` → `Upload files`
3. לתמונה חדשה בשם שלא ברשימה — תשלחו לי את השם ואני אשייך אותה למקום המתאים
   (בדיוק כמו שעשינו עם חמש התמונות האחרונות).
4. **להחלפת תמונה קיימת**: מעלים קובץ חדש עם **אותו שם בדיוק** (למשל
   `IMG_4623.jpeg`) — הוא מחליף את הקודם אוטומטית.

## לפני ההעלאה

1. **סיבוב** — ודאו שהתמונה מוצגת בכיוון הנכון. תמונה שצולמה בטלפון ונשמרה "על הצד"
   תופיע מסובבת גם באתר. אם צריך, סובבו אותה בגלריה של הטלפון ושמרו לפני ההעלאה.
2. **גודל** — רוחב של 1600–2000 פיקסלים מספיק בהחלט. תמונות ישירות מהטלפון
   (4000 פיקסלים ומעלה) יאטו את האתר משמעותית — כדאי להקטין.
3. **פורמט** — `.jpg` / `.jpeg`. אם התמונות בפורמט HEIC, יש להמיר קודם
   (בהגדרות האייפון: מצלמה → פורמטים → "הכי תואם").
