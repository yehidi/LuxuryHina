עד שקובץ מועלה, המקום שלו מוצג עם העיצוב האורנמנטלי — האתר לא נשבר ולא מוצג "תמונה שבורה".

## לפני ההעלאה

1. **סיבוב** — ודאו שהתמונה מוצגת בכיוון הנכון. תמונה שצולמה בטלפון ונשמרה "על הצד"
   תופיע מסובבת גם באתר. אם צריך, סובבו אותה בגלריה של הטלפון ושמרו לפני ההעלאה.
2. **גודל** — רוחב של 1600–2000 פיקסלים מספיק בהחלט. תמונות ישירות מהטלפון
   (4000 פיקסלים ומעלה) יאטו את האתר משמעותית — כדאי להקטין.
3. **פורמט** — `.jpg`. אם התמונות בפורמט HEIC של אייפון, יש להמיר ל-JPG
   (בהגדרות האייפון: מצלמה → פורמטים → "הכי תואם").

## איך מעלים מהאייפון

1. גלשו ל-`github.com/yehidi/LuxuryHina` בדפדפן
2. היכנסו לתיקייה `images`
3. `Add file` → `Upload files`
4. בחרו את התמונות מהגלריה, ודאו שהשמות תואמים לטבלה, ולחצו `Commit changes`

תוך דקה-שתיים התמונות יופיעו באתר.
