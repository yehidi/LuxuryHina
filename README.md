# אתר נחיתה - הפקת חינות יוקרתיות

עמוד נחיתה יחיד, רספונסיבי (מובייל ומחשב), לעסק הפקת אירועי חינה יוקרתיים. נבנה ב-HTML/CSS/JS פשוט, ללא תלות בבנייה (build) או בפריימוורק.

## מבנה הקבצים

- `index.html` - כל התוכן והמבנה של העמוד
- `style.css` - העיצוב: טיפוגרפיה עורכת (Frank Ruhl Libre + Heebo), פלטת שנהב/פחם/זהב מאופקת, גריד עריכתי א-סימטרי, ואנימציות מינימליות
- `script.js` - אפקטי גלילה (reveal, progress bar), קרוסלת המלצות, מונים מונפשים, קורסור מותאם וטיפול בסיסי בטופס יצירת הקשר

כל האנימציות מכבדות `prefers-reduced-motion` ומושבתות אוטומטית עבור משתמשים שמעדיפים תנועה מופחתת. הקורסור המותאם והאפקטים העדינים על הכפתורים פעילים רק במכשירים עם עכבר (לא בנייד/מגע).

התמונות בגלריה ובסקציית "אודות" הן כרגע "לוחות" גרפיים (איור קווי דקורטיבי בגוון זהב על רקע פחם/יין) ולא צילומים - זו בחירת עיצוב מכוונת לשלב הזה, לא placeholder זמני שצריך למהר להחליף.

## מה עוד צריך להשלים

1. **שם העסק** - להחליף בכל מקום שמופיע "שם העסק" (בכותרת, בלוגו ובפוטר).
2. **פרטי קשר** - טלפון, וואטסאפ, אימייל ואינסטגרם בסקציית "צור קשר" ובקישור ה-WhatsApp בכפתור הראשי (`https://wa.me/972500000000`).
3. **תמונות אמיתיות** (אופציונלי) - אפשר להשאיר את הלוחות הגרפיים כפי שהם, או להחליף אותם בתמונות אמיתיות מהאירועים (קבצי `.jpg`/`.webp`, עדכון ב-`index.html` ו-`style.css`).
4. **טקסטים** - לעדכן את הטקסט בסקציות "אודות", "השירותים שלנו" ו"לקוחות ממליצים" בהתאם לעסק בפועל.
5. **טופס יצירת קשר** - הטופס כרגע רק מציג הודעת אישור בצד הלקוח ואינו שולח בפועל. כדי שהפניות יגיעו אליכם צריך לחבר אותו לשירות כמו Formspree / EmailJS / Google Forms, או לבנות צד שרת קטן.

## הרצה מקומית

פשוט פתחו את `index.html` בדפדפן, או הריצו שרת סטטי פשוט:

```bash
python3 -m http.server 8000
```

ואז גשו ל-`http://localhost:8000`.

## פרסום עם GitHub Pages

1. היכנסו להגדרות ה-repository ב-GitHub → `Settings` → `Pages`
2. תחת "Build and deployment" בחרו Source: `Deploy from a branch`
3. בחרו את הענף `main` ותיקיית root `/`
4. שמרו - האתר יהיה זמין תוך מספר דקות בכתובת שתופיע שם
