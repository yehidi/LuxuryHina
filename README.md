# LuxuryHina — אתר נחיתה

עמוד נחיתה יחיד, רספונסיבי (מובייל / טאבלט / מחשב), לעסק הפקת אירועי חינה יוקרתיים.
HTML/CSS/JS בלבד — ללא framework, ללא שלב build, וללא ספריות חיצוניות.

**כיוון עיצובי:** "Candlelit Atelier" — רקע פחם חם, אור נרות סלקטיבי, זהב מתכתי,
אורנמנטיקה מזרחית מקורית, וטיפוגרפיה בקנה מידה דרמטי. יש גם שני עיצובים
נוספים (Light, Bold) שאפשר להחליף ביניהם דרך פאנל הניהול — ראו למטה.

## פאנל ניהול

יש עמוד ניהול נפרד, `admin.html`, שמאפשר לערוך את כל התוכן, התמונות,
הסרטונים ואפילו את סגנון העיצוב של האתר — **בלי לגעת בקוד**. המדריך
המלא, שלב אחר שלב, נמצא ב-**[MANUAL.md](MANUAL.md)**.

## החלטות טכניות

### גופנים מאוחסנים מקומית (חשוב)
הגופנים **אינם** נטענים מ-Google Fonts אלא מהתיקייה `fonts/`. זו לא בחירה שרירותית:
בגרסאות קודמות טעינת הגופנים מ-CDN נכשלה בשקט (`ERR_CONNECTION_RESET`) והדף הוצג
בגופני ברירת מחדל של המערכת. אחסון מקומי מבטיח שהאתר תמיד נראה כפי שתוכנן, וגם:
מהיר יותר, ללא תלות בצד שלישי, ללא קפיצת פריסה (FOUT), ותואם פרטיות.

**החלפת גופן** מחייבת גם עדכון של בלוקי ה-`@font-face` בראש `style.css`.

### תמונות וסרטונים
שכבת המדיה נטענת ב-`script.js` דרך `mountPhoto()` / `mountVideo()`: הקובץ נבדק מראש
ומוזרק לדף **רק אם הטעינה הצליחה**. קובץ חסר פשוט לא מוצג — ובמקומו נשאר הלוח
האורנמנטלי, בלי אייקון "תמונה שבורה" או וידאו תקוע. לכן אפשר להעלות מדיה בהדרגה,
ולוודא — ראו `images/README.md` ו-`videos/README.md`.

בכל מקום שיש גם תמונה וגם סרטון (כרגע: ה-Hero ולוחות הגלריה), **הסרטון גובר**.
בגלריה הסרטון מתנגן רק בריחוף עכבר (לא כל שישה יחד) ומסומן בתגית ▶ קטנה; ב-Hero
הוא מתנגן ברקע אוטומטית (מושתק, בלולאה).

כל עוד חסרים קבצים, יופיעו ב-console שגיאות 404 — זה מנגנון הבדיקה עצמו, והן
נעלמות ברגע שהקבצים מועלים.

הוספת מדיה = העלאת קובץ בשם הנכון לתיקייה (`images/` או `videos/`).
**אין צורך לגעת בקוד.**

### אורנמנטיקה
כל המוטיבים (מנדלה, רוזטה, בּוטֶה/פייזלי, גפן מהנדי, וכן דגמי girih / ogee / scallop
לריצוף) נוצרו גאומטרית ומוטמעים כ-SVG. הם משתמשים ב-`currentColor`, כך שאפשר לשלוט
בצבע ובשקיפות דרך CSS.

### שיווק והמרה
- **כפתור וואטסאפ צף** בכל גלילה (נעלם בפוטר, שם ממילא יש אייקון וואטסאפ).
- **אייקוני וואטסאפ / אינסטגרם / פייסבוק / טלפון / אימייל** בסקציית הקשר ובפוטר.
- **סקציית "איך זה עובד"** (4 שלבים) — מפחיתה חשש לפני פנייה.
- **שאלות נפוצות** — מטפלת בהתנגדויות (מחיר, זמן מראש, אזור שירות) ומביאה תנועה מגוגל.
- **תמונת שיתוף (OG)** — כששולחים את הקישור בוואטסאפ מופיעה תמונת האוהל, לא ריק.
- **נתונים מובנים** (JSON-LD, LocalBusiness) לתוצאות עשירות בגוגל.

### נגישות ותנועה
- כל הטקסטים נבדקו ועומדים בתקן **WCAG AA** לניגודיות.
- `prefers-reduced-motion: reduce` מבטל את כל האנימציות ומציג עמוד סטטי ומלא.
- הקורסור המותאם, ה-parallax והאפקטים המגנטיים פעילים **רק** במכשירים עם עכבר.
- ה-lightbox תומך במקלדת (Esc / חיצים / מלכודת פוקוס) ובהחלקה במגע.

## הטופס — איך פניות מגיעות אליכם

אין שרת לאתר, ולכן במקום להעמיד פנים ש"נשלח" ולאבד את הפנייה, **הטופס מרכיב
הודעת וואטסאפ מוכנה** עם כל הפרטים שמולאו (שם, טלפון, תאריך, מספר אורחים,
והודעה חופשית) ופותח אותה בוואטסאפ שלכם. הלקוח רק לוחץ "שלח".

היתרון: זה עובד היום, בלי תשלום ובלי תלות בשירות חיצוני, ומגיע לערוץ שאתם ממילא
נמצאים בו. מספר היעד נקרא מתוך קישורי הוואטסאפ שבדף, כך שאין כפילות בקוד.

אם בעתיד תרצו שהפניות יגיעו גם למייל, אפשר לחבר את הטופס ל-Formspree / EmailJS
במקביל.

## מה עוד צריך להשלים

1. **המלצות אמיתיות** — "משפחת כהן / לוי / אזולאי" הן **דוגמאות שנכתבו כ-placeholder**,
   לא לקוחות אמיתיים. שתי המלצות אמיתיות עם שם ותאריך שוות יותר משלוש מומצאות.
2. **המספרים בסקציית "אודות"** — "+150 אירועים", "10 שנות ניסיון", "100% התאמה אישית"
   **נכתבו כ-placeholder ולא אומתו מולכם.** יש לעדכן למספרים הנכונים או להסיר.
   פרסום נתון שאינו נכון הוא חשיפה מיותרת.
3. **תשובות ה-FAQ** — נוסחו בזהירות ובאופן כללי (בלי מחירים או התחייבויות מספריות),
   אבל כדאי לעבור עליהן ולוודא שהן משקפות את המדיניות שלכם בפועל.
4. **תמונות וסרטונים נוספים** — ראו `images/README.md` ו-`videos/README.md`.

## הרצה מקומית

```bash
python3 -m http.server 8000
```
ואז לגלוש ל-`http://localhost:8000`.
פתיחה ישירה של `index.html` דרך `file://` תעבוד גם, אך שרת מקומי מומלץ לטעינת הגופנים.

## פרסום עם GitHub Pages

1. `Settings` → `Pages`
2. Source: `Deploy from a branch`
3. Branch: `main`, תיקייה `/ (root)` → **Save**
4. תוך מספר דקות האתר יהיה זמין בכתובת שתוצג שם.
