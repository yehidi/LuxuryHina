# LuxuryHina — אתר נחיתה

עמוד נחיתה יחיד, רספונסיבי (מובייל / טאבלט / מחשב), לעסק הפקת אירועי חינה יוקרתיים.
HTML/CSS/JS בלבד — ללא framework, ללא שלב build, וללא ספריות חיצוניות.

**כיוון עיצובי:** "Candlelit Atelier" — רקע פחם חם, אור נרות סלקטיבי, זהב מתכתי,
אורנמנטיקה מזרחית מקורית, וטיפוגרפיה בקנה מידה דרמטי.

## מבנה הקבצים

| קובץ | תיאור |
| --- | --- |
| `index.html` | תוכן ומבנה + ספריית האורנמנטים (SVG `<symbol>` / `<pattern>` מוטמעים) |
| `style.css` | מערכת העיצוב המלאה: טוקנים, טיפוגרפיה, אנימציות, responsive |
| `script.js` | intro, split-text, reveals, parallax, bokeh, מונים, קורסור, lightbox, קרוסלה, ולידציית טופס |
| `fonts/` | **גופנים מאוחסנים מקומית** (woff2, ~164KB) |

## החלטות טכניות

### גופנים מאוחסנים מקומית (חשוב)
הגופנים **אינם** נטענים מ-Google Fonts אלא מהתיקייה `fonts/`. זו לא בחירה שרירותית:
בגרסאות קודמות טעינת הגופנים מ-CDN נכשלה בשקט (`ERR_CONNECTION_RESET`) והדף הוצג
בגופני ברירת מחדל של המערכת. אחסון מקומי מבטיח שהאתר תמיד נראה כפי שתוכנן, וגם:
מהיר יותר, ללא תלות בצד שלישי, ללא קפיצת פריסה (FOUT), ותואם פרטיות.

**החלפת גופן** מחייבת גם עדכון של בלוקי ה-`@font-face` בראש `style.css`.

### תמונות
שכבת התמונות נטענת ב-`script.js` דרך `mountPhoto()`: הקובץ נטען מראש ומוזרק לדף
**רק אם הטעינה הצליחה**. קובץ חסר פשוט לא מוצג — ובמקומו נשאר הלוח האורנמנטלי,
בלי אייקון "תמונה שבורה". לכן אפשר להעלות תמונות בהדרגה.

כל עוד חסרות תמונות, יופיעו ב-console שגיאות 404 — זה מנגנון הבדיקה עצמו, והן
נעלמות ברגע שהקבצים מועלים.

הוספת תמונה = העלאת קובץ בשם הנכון לתיקיית `images/`. **אין צורך לגעת בקוד.**

### אורנמנטיקה
כל המוטיבים (מנדלה, רוזטה, בּוטֶה/פייזלי, גפן מהנדי, וכן דגמי girih / ogee / scallop
לריצוף) נוצרו גאומטרית ומוטמעים כ-SVG. הם משתמשים ב-`currentColor`, כך שאפשר לשלוט
בצבע ובשקיפות דרך CSS.

### נגישות ותנועה
- כל הטקסטים נבדקו ועומדים בתקן **WCAG AA** לניגודיות.
- `prefers-reduced-motion: reduce` מבטל את כל האנימציות ומציג עמוד סטטי ומלא.
- הקורסור המותאם, ה-parallax והאפקטים המגנטיים פעילים **רק** במכשירים עם עכבר.
- ה-lightbox תומך במקלדת (Esc / חיצים / מלכודת פוקוס) ובהחלקה במגע.

## מה עוד צריך להשלים

1. **תמונות** — ראו `images/README.md`. זה השדרוג הכי משמעותי שנשאר.
2. **פרטי קשר** — טלפון, וואטסאפ ואימייל בסקציית "צור קשר" עדיין placeholder,
   וכן קישור ה-WhatsApp בכפתור הראשי (`https://wa.me/972500000000`).
   האינסטגרם כבר מעודכן ל-[@luxury_hina](https://www.instagram.com/luxury_hina).
3. **טופס יצירת קשר** — כרגע מתבצעת ולידציה בצד הלקוח בלבד והטופס **אינו שולח**.
   כדי שפניות יגיעו אליכם יש לחבר אותו ל-Formspree / EmailJS / Google Forms
   או לנקודת קצה משלכם (ראו ההערה ב-`script.js`).
4. **טקסטים** — לעדכן "אודות", "השירותים" ו"המלצות" לפי העסק בפועל.
   גם ההמלצות ("משפחת כהן" וכו') הן דוגמה בלבד.

## הרצה מקומית

```bash
python3 -m http.server 8000
```
ואז לגלוש ל-`http://localhost:8000`.
פתיחה ישירה של `index.html` דרך `file://` תעבוד גם, אך שרת מקומי מומלץ לטעינת הגופנים.

## פרסום עם GitHub Pages

1. `Settings` → `Pages`
2. Source: `Deploy from a branch`
3. Branch: `main`, תיקייה `/ (root)` → **Save**
4. תוך מספר דקות האתר יהיה זמין בכתובת שתוצג שם.
